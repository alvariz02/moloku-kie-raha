# MOLOKU — Warisan Maluku Utara
Website statis berbahasa Indonesia dengan arah desain komik Sejarah Morotai: judul besar, panel berwarna, latar berganti mengikuti bab, dan navigasi bawah.

Jalankan: `python -m http.server 4173 --directory dist`, lalu buka http://localhost:4173.

Fitur: cerita tradisi, pilihan kepulauan, filter dan pencarian koleksi, dialog detail dan kredit, kuis budaya, navigasi bab, indikator progres. Tidak memerlukan instalasi dependensi. Foto dan sumber tercantum di website dan dist/assets/credits.json. Hak foto mengikuti penerbit Indonesia Travel.
